# 台股策略作战台

一套 regime-aware 的台股策略监控系统：**大盘策略切换 + 散户进场闸门 + 个股体检排雷**。
资料来源 TWSE + FinMind，回测 2018–2026、point-in-time、分割调整。

## 🖥️ 网页（GitHub Pages）

- **作战台（主力）**：`warroom.html` — 大盘作战 + 个股体检，每天看这个
- 研究报告（静态）：`strategy.html`（价值动能）、`elliott.html`（波浪验证）、`ls_backtest.html`（散户多空比回测）
- 单项详情：`gatelight.html`（进场闸门）、`dashboard.html`（策略健康度）、`stockcheck.html`（个股体检）

> GitHub Pages 上线后网址：`https://<你的帐号>.github.io/<repo名>/warroom.html`

## 🔄 自动更新（Windows）

### 首次设定
```bat
:: 1. clone
git clone https://github.com/<你的帐号>/<repo名>.git
cd <repo名>

:: 2. 首次全抓三年资料 (约 1-2 小时, 只需一次)
python bootstrap.py
```

### 设定每交易日自动更新（一天两次）
用 **Windows 工作排程器 (Task Scheduler)**，建**两个**基本工作：

**工作一（15:30 盘后先更新）**
1. 名称：`tw-stock-update-1530`
2. 触发程序：**每天**、开始时间 **15:30**
3. 动作：启动程式 — 程式 `python`、引数 `update.py`、起始位置 = repo 完整路径

**工作二（21:30 补融资融券，最完整）**
1. 名称：`tw-stock-update-2130`
2. 触发程序：**每天**、开始时间 **21:30**
3. 动作同上

> 为什么两次：15:30 时量价/法人期货/外资连买已出（散户闸门可更新），但**融资融券要 21:00 才出**，所以 21:30 再补一次抓齐。
> 跑两次不会重复：抓取「内容相同不写入」、git「无变更不 push」，第二次只补差异。
> `update.py` 内建判断周末不抓（台股无新资料）；每次写 `update.log` 可查纪录。

### 资料更新时点参考
| 资料 | 官方更新 |
|------|---------|
| 个股量价/本益比 | ~14:30-15:00 |
| 三大法人期货未平仓（散户闸门） | ~15:00 |
| 三大法人现货买卖超（外资连买） | ~15:00-16:00 |
| 融资融券 | ~21:00（最晚）|

→ 设 **21:30** 抓，确保所有资料都上线、一次抓齐最完整。
