結論

找到了有 edge 的報酬引擎，但它的 -58% MDD 是結構性的、解不掉。「適不適合你」是個人風險承受度問題，不是技術問題。能試的因子與風控都試完，再調參數只會 overfit（P5）— 研究誠實收斂，就此定案。

定位 — 先寫定位，再寫規則

🎯 首要目標

選股 alpha — 找「估值相對便宜 + 有題材動能」的股票。不是控 MDD，那是 Layer C 的活。

⊘ 放棄了什麼

放棄純噴出飆股尾部報酬（低 P/E 會濾掉最貴的 AI 飆股）；放棄超短線 / 當沖。

✕ 誰不該用

想抓當沖、隔日沖、追高動能的人。這是週~月級持有，目標不合就別用。

核心洞見：價值（低 P/E）與動能（族群 / 價格強度）是相關性最低的兩個因子，互補。 單用價值會踩價值陷阱、單用動能會追在頂部；兩者交集才是甜蜜點。

  • 跨組合進出加總自然 ≥ 1 筆/週
  • 有訊號才動、沒訊號 pass（T1 四綠精神）

已知 caveats — 不藏

  • 市值用現股數快照：歷史前150宇宙有輕微 look-ahead（增減資個股偏），大型股影響小

  • 本益比虧損標記：EPS ≤ 0 時 P/E =「-」，直接剔除，不當成便宜
  • 交易成本：手續費 + 證交稅 0.3% + 滑價全扣進淨損益
